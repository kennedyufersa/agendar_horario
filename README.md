# README

## Como fazer um commit neste README

Siga os passos abaixo para registrar alterações neste arquivo no Git:

1. Abra o terminal na pasta do projeto.
2. Edite este arquivo com as informações desejadas.
3. Adicione as alterações ao controle de versão:
   ```bash
   git add README.md
   ```
4. Crie um commit com uma mensagem clara:
   ```bash
   git commit -m "Atualizar README com horários de apresentação"
   ```
5. Envie as alterações para o repositório:
   ```bash
   git push origin main
   ```
